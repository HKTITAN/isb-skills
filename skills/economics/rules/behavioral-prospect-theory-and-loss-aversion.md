**Core Insights**
- Loss aversion: Losses loom approximately 2x larger than equivalent gains in decision-making
- Reference dependence: Individuals evaluate outcomes relative to reference point (often current state), not absolute terms
- Diminishing sensitivity: Sensitivity to changes decreases as one moves away from reference point
- Certainty effect: People overweight certain outcomes relative to probable outcomes

**Decision Weights and Probabilities**
- Low probability events overweighted: Explains preference for insurance and participation in lotteries
- High probability events underweighted: Explains risk-seeking behavior for negative outcomes
- Reflection effect: Risk preferences reverse depending on whether prospects are gains or losses
- Isolation effect: Individuals ignore common elements of alternatives; focus on differing elements

**Value Function Properties**
- Nonlinear value around reference point
- Steeper for losses than gains (asymmetric)
- Concave for gains (diminishing sensitivity to larger gains)
- Convex for losses (diminishing sensitivity to larger losses)
- First dollars gained/lost matter most; incremental changes worth less

**Business Applications**
- Framing effects: Presenting same option as gain vs loss changes decisions (surgery: "90% survival" vs "10% mortality")
- Pricing: Loss framing (save $10) more effective than gain framing (cost only $40)
- Negotiation: Sellers emphasize gains of sale; buyers emphasize losses of payment
- Product design: Default options leverage loss aversion; changing defaults dramatically affects choices
- Compensation: Loss framing ("lose bonus if miss target") more motivating than gain framing (legally risky)
