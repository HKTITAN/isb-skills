**Nudge Design Principles**
- Identify default: What happens if customer does nothing? Redesign if not aligned with desired outcome
- Reduce complexity: Simplify choices; remove unnecessary information
- Make salient: Highlight important information; use prominent positioning
- Leverage social norms: Show what others do; create conformity pressure

**Incentive Design**
- Align incentives: Pay for outcomes you care about; base compensation on metrics reflecting firm goals
- Reduce moral hazard: Make agent bear consequences of effort choices; monitor if unobservable
- Manage reference points: Consider loss aversion; frame improvements as gains, losses as potential
- Account for loss aversion: Threats more motivating than promises; change framing from loss perspective

**Negotiation Tactics**
- Anchoring: Make first offer; expect second offer anchors on yours
- Loss framing: Focus on counterparty's losses from no deal rather than gains from accepting
- Reference point shift: Move negotiation reference from status quo to BATNA
- Commitment building: Visible commitment increases credibility; public statements costly to retract
