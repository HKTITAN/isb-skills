**Incentive Compatibility**
- Definition: Mechanism designed so that revealing true information is in each player's best interest
- Strategy-proofness: No player can do better by lying about preferences/values
- Example: Vickrey auction is incentive-compatible (truthful bidding dominant strategy)
- Application: Tax system, voting systems, matching algorithms

**Individual Rationality**
- Definition: Participation constraint; mechanism ensures each player at least as well off participating as not
- Voluntary participation: Cannot force participation if payoff is negative
- Example: Insurance premium should not exceed expected benefit value for any customer type
