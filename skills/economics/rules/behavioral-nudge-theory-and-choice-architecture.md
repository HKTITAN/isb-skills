**EAST Framework (Behavioral Insights Team)**
- Easy: Reduce friction; simplify choices; require minimal effort
- Attractive: Make desired behavior salient; use color, salience, positive framing
- Social: Leverage social norms; show others' behavior; use social proof
- Timely: Prompt decision at decision-making moment; capitalize on receptiveness

**Choice Architecture Principles**
- Defaults matter: Default option chosen by 70-90% of people; select defaults strategically
- Reduce choice overload: Too many options paralyzes; limit meaningful alternatives (3-5 optimal)
- Increase salience: Highlight important information; use prominent positioning
- Simplify complexity: Use metaphors, analogies, clear language
- Social norms: Display others' choices; "most people do X"; creates conformity pressure
- Comparison: How alternatives compared affects choice; anchoring biases toward reference option

**Libertarian Paternalism**
- Definition: Nudging people toward better choices while preserving freedom
- No mandatory requirements; choices remain available; individual retains autonomy
- Contrasts with: Paternalism (mandate behavior) and libertarianism (no guidance)
- Examples: Automatic enrollment with opt-out; calorie display without restricting purchases
- Outcome: Dramatically higher participation when default aligns with preferred choice

**Ethical Considerations**
- Transparency: Users should understand they're being influenced; dark patterns unethical
- Manipulation vs nudge: Nudges inform better decisions; manipulation exploits biases for seller benefit
- Whose benefit: Nudges should benefit choice-maker, not exploit for company benefit
- Disclosure: If nudge conflicts with user interest, should be transparent about incentives

**Business Applications**
- Enrollment: Automatic enrollment dramatically increases participation (pensions, insurance, health plans)
  - 401(k) with opt-in: ~30% participation; with opt-out: ~80% participation
- Organ donation: Default opt-in vs opt-out changes donation rates 85% vs 4%
- Savings: Save More Tomorrow program commits to savings increases on future raises
- Sustainability: Social comparisons ("neighbors use less energy") reduce consumption more than price signals
- Checkout design: Add-on suggestions, default quantities, express checkout options influence purchases
- Salience: Tax-inclusive prices make taxes visible; gas tax more noticeable than embedded sales tax
