**Structure matters**: Guide audience from current state through analysis to recommended action.

**Effective presentations**:
1. Opening hook (attention-getting, establishes relevance)
2. Challenge definition (what problem or opportunity?)
3. Current state analysis (what's the situation now?)
4. Root cause or opportunity analysis (why?)
5. Options and evaluation (what approaches considered? why some rejected?)
6. Recommendation (clear, specific, actionable)
7. Implementation roadmap (what happens next?)
8. Closing statement (memorable restatement of key benefit)

**Audience adaptation**: Same analysis requires different presentations for different audiences.
- C-suite: 10-15 minutes, focus on business impact and risk
- Functional team: 30-40 minutes, deep-dive on methodology and alternatives
- Board: Balance conviction with acknowledgment of risks

**Visual communication**:
- One idea per slide
- Use color and size to highlight key data
- Match chart type to message (line = trends, bar = comparisons, etc.)
- Minimize decoration; maximize data-ink ratio

**Delivery**:
- Pace: ~150 words per minute; vary to emphasize
- Volume: Audible to back of room; modulate for emphasis
- Tone: Vary to match content; avoid monotone
- Eye contact: Connect with multiple people throughout room
- Body language: Confident posture, natural gestures, strategic movement
- Appearance: Conservative, professional, appropriate to context

**Handling questions**:
1. Listen fully before responding
2. Pause thoughtfully before answering
3. Clarify the question if needed
4. Answer directly and support with evidence
5. Bridge back to key message
6. Admit unknowns rather than fabricate
