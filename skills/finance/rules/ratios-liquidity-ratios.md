**Current Ratio** = Current Assets / Current Liabilities

Can the company pay short-term obligations?

Example:
```
Current Assets: $50M (cash $10M, AR $20M, inventory $20M)
Current Liabilities: $30M
Current Ratio = 1.67

Healthy: 1.5-2.0
Too high (>3.0): Idle cash, inefficient
Too low (<1.0): Distress risk
```

**Quick Ratio** = (Current Assets - Inventory) / Current Liabilities

More conservative; only counts quickly liquidatable assets.

```
Same example: ($50M - $20M) / $30M = 1.0
Shows only $30M cash/AR available against $30M liabilities
```

**Cash Ratio** = Cash / Current Liabilities

Most conservative; rarely >0.5 (companies need working capital).

**Operating Cash Flow Ratio** = OCF / Current Liabilities

Better predictor of solvency than current ratio (cash-based, not accounting).

Ratio >1.0 is healthy.
