**1. Operational Improvement**

Improve margins through cost reduction, pricing power, or revenue growth.

```
Example: Acquire company with 10% EBITDA margin
Improve to 15% through operational efficiency
EBITDA increases 50% → Enterprise value increases 50%
If purchased at 6x EBITDA, exit at 6x higher EBITDA = 2.5x return
```

**2. Multiple Arbitrage**

Buy at cyclical low multiple, sell at peak multiple.

```
Buy at 6x EBITDA (downturn), sell at 12x EBITDA (recovery)
2x multiple expansion = 2x value increase
```

**3. Leverage**

Use debt to amplify equity returns.

```
$100M investment, 25% equity, 75% debt
If returns exceed debt cost, equity holders capture outsized returns
Risk: High leverage dangerous if operations deteriorate
```

**4. Dividend Recaps**

Special dividend to GPs from refinancing; reduces equity at risk while maintaining ownership.
