**Cap Rate (Capitalization Rate)** = Net Operating Income / Property Value

```
Example: Office building NOI $1M, value $10M
Cap Rate = 10%

Inverse of P/E for real estate
Higher cap rate = higher yield or higher risk
Market cap rates: 6-10% typical
```

**NOI (Net Operating Income)**

```
Gross Rental Income:  $2M
- Vacancy loss:       $(0.2M)  (assume 10% vacancy)
+ Other income:       $0.1M    (parking, laundry)
= Effective Gross Income: $1.9M

- Operating Expenses:
  Property Tax:       $(0.4M)
  Insurance:          $(0.1M)
  Maintenance:        $(0.2M)
  Management:         $(0.1M)
  = Total OpEx: $(0.8M)

= NOI: $1.1M
```

**Property Valuation:**

Method 1: Income Approach
```
Value = NOI / Cap Rate = $1.1M / 8% = $13.75M
```

Method 2: Sales Comparison (comparables)

Method 3: Cost Approach (rebuild cost + land - depreciation)

**Mortgage Financing:**
```
Typical LTV (Loan-to-Value): 70-75%
Down payment: 25-30%
Terms: 15-30 years

Amortization affects cash flow:
Early years: Interest >> Principal (tax-deductible)
Later years: Principal >> Interest
Free Cash Flow = NOI - Principal & Interest payments
```

**REITs (Real Estate Investment Trusts)**

Must distribute 90% of taxable income. Valuation: P/FFO multiple (10-18x).

FFO (Funds From Operations) = Net Income + D&A - Gains on Sales

More stable than net income.
