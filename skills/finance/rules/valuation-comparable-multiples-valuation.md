Uses market multiples of comparable companies.

**Enterprise Value / EBITDA**

Most common multiple; compares across companies regardless of capital structure or tax rates.

```
EV/EBITDA = (Market Cap - Cash + Debt) / EBITDA

Example:
Market Cap: $1,000M
Cash: $100M
Debt: $200M
EBITDA: $200M

EV = $1,000 - $100 + $200 = $1,100M
EV/EBITDA = $1,100M / $200M = 5.5x

Interpretation: Market pays $5.50 for every $1 of EBITDA
```

Typical multiples by industry:
```
Tech/SaaS: 15-25x
Utilities: 8-12x
Manufacturing: 8-12x
Retail: 6-9x
Banks: 8-10x
```

**Price-to-Earnings (P/E)**

P/E = Stock Price / EPS (or Market Cap / Net Income)

```
Example:
Stock price: $50
EPS: $2
P/E = 25x

Interpretation: Market pays $25 for every $1 of earnings
```

Issues:
- Affected by capital structure (leverage increases EPS artificially)
- Affected by tax rates (different across jurisdictions)
- Forward P/E (projected) vs. Trailing P/E (historical)

**Price-to-Book (P/B)**

P/B = Stock Price / Book Value Per Share

```
Market Cap: $1,000M
Shareholders' Equity: $600M
P/B = 1.67x
```

Useful for asset-heavy businesses (banks, insurance), less so for intangible-heavy (tech).

**EV/Revenue**

EV / Annual Revenue

Used for unprofitable growth companies (EBITDA is negative, so P/E meaningless).

```
EV: $500M, Revenue: $100M
EV/Revenue = 5x
```

Higher for high-margin businesses (better recurring revenue).

**Peer Selection:**

- Same industry (similar business model)
- Similar size (growth stage, scale)
- Similar geography (regulatory, macro environment)
- Typically use 3-5 close peers + 5-10 broader peers
- Apply adjustments (10-20%) for differences
