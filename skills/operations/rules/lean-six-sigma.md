Structured problem-solving framework targeting 3.4 defects per million opportunities (DPMO) corresponding to 6 standard deviations from specification accounting for process drift.

**DMAIC Methodology**:

1. **Define**: Project charter, business case, scope, timeline, benefits. SIPOC (Supplier-Input-Process-Output-Customer) maps process boundaries and stakeholders. Problem statement: "Currently... should be..."

2. **Measure**: Data collection plan (what, how, who, when). Baseline metrics. Measurement system analysis (MSA) ensures data reliability. Capability analysis compares process to specifications.

3. **Analyze**: Root cause analysis (5 Whys, fishbone, fault tree). Hypothesis testing confirms potential causes. Pareto analysis prioritizes vital few problems.

4. **Improve**: Design of Experiments (DOE) systematically tests factor combinations to optimize response. Piloting and validation on small scale before rollout. Solution selection balancing effectiveness, cost, feasibility.

5. **Control**: Control plans to sustain gains. SPC implementation with control charts. Documentation and standardization.
