**PDCA Cycle** (continuous improvement loop):
- **Plan**: Define problem, set target, establish countermeasures (root cause → solution → test plan)
- **Do**: Implement on small scale (pilot in one area to reduce risk)
- **Check**: Measure results against target (did we hit the goal? What's the gap?)
- **Act**: Standardize if successful, adjust if not (lock in gains, or iterate)
- Repeat: Once stabilized, find next problem (never "done"; continuous improvement)

**Seven QC Tools**:
1. Flowchart: Visualizes process
2. Check sheet: Tallies frequency of events
3. Histogram: Shows distribution of data
4. Pareto chart: Prioritizes by impact (80/20 rule)
5. Cause-and-effect diagram (fishbone): Explores root causes systematically (People, Process, Plant, Materials, Methods, Environment, Measurement)
6. Scatter plot: Shows relationship between two variables
7. Control chart: Monitors process over time

**Fishbone Diagram**: Categories typically People, Process, Plant, Materials, Methods, Environment, Measurement.

**5 Whys**: Repeatedly ask "why" (5 times) to drill from symptom to root cause.
