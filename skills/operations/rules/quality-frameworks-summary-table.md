| Challenge | Framework | Key Metrics | Output |
|-----------|-----------|------------|--------|
| Process Waste | Lean/TIMWOODS | Cycle time, WIP, throughput, takt time | Waste identification and elimination |
| Quality Defects | Six Sigma/DMAIC | DPMO, Cpk, Control limits | Root causes, process improvements |
| Inventory Costs | EOQ, ROP, Safety Stock | Carrying cost, order cost, service level | Optimal order quantity and timing |
| Supply Chain Coordination | CPFR, VMI, Information Sharing | Bullwhip coefficient, forecast error | Reduced inventory, better responsiveness |
| Project Duration | CPM/PERT | Critical path, slack, schedule variance, SPI | Baseline schedule, risk assessment |
| Project Cost | EVM | CPI, SPI, EAC, ETC | Cost status, forecast accuracy |
| Capacity Planning | Queuing Theory, Simulation | Queue length, wait time, utilization, OEE | Staffing, capacity requirements |
| Supply Chain Network | Network Optimization | Total cost, service level, facility count | Optimal network design |
| Strategic Alignment | Order Winners/Qualifiers | Performance on order winners and qualifiers | Strategic operations priorities |
| Demand Forecast | Time Series, Regression, ML | MAPE, MAE, tracking signal, bias | Accurate demand predictions |
| Risk Quantification | Monte Carlo Simulation | VaR, Expected Shortfall, probability distributions | Risk profiles, scenario analysis |
| Bottleneck Management | Theory of Constraints (TOC) | Throughput, constraint utilization, DBR | Focused improvements on constraint |
| Optimization Problems | Linear Programming, Integer Programming | Shadow prices, reduced costs, sensitivity ranges | Allocation decisions, "what-if" insights |
| Inventory Positioning | Network Design, Centralization vs. Decentralization | DIO, safety stock pooling benefit | Warehouse locations and inventory levels |
| Schedule Management | Critical Path, PERT, Critical Chain | Slack, buffer consumption, schedule variance | Protected schedule, reduced delays |
