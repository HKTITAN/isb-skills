**Inventory Management**:
- Economic Order Quantity: Q* = √(2DS/H)
- Reorder Point: ROP = (d × L) + SS
- Safety Stock: SS = Z × σ × √L
- Total Inventory Cost: TC = (D/Q)×S + (Q/2)×H + (Demand)×(Unit Cost)

**Demand Forecasting**:
- Moving Average: F_t = (D_{t-1} + D_{t-2} + ... + D_{t-n}) / n
- Exponential Smoothing: F_t = α × D_{t-1} + (1-α) × F_{t-1}
- MAPE = Σ|D_t - F_t| / D_t × 100 / n
- Tracking Signal = Cumulative Forecast Error / MAD

**Project Management**:
- PERT Expected Time: (O + 4M + P) / 6
- PERT Variance: ((P - O) / 6)²
- Slack = LS - ES (or LF - EF)
- Schedule Performance Index: SPI = EV / PV
- Cost Performance Index: CPI = EV / AC

**Quality and Process Control**:
- Process Capability: Cp = (USL - LSL) / (6σ)
- Centered Capability: Cpk = min[(USL - mean)/(3σ), (mean - LSL)/(3σ)]
- Six Sigma DPMO by sigma level: 1σ = 308,538; 2σ = 69,146; 3σ = 6,210; 4σ = 233; 5σ = 3.4; 6σ = 0.002
- Control Limits: Mean ± 3σ (±2σ for warning limits)

**Queuing Theory**:
- Little's Law: L = λ × W (average in system = arrival rate × average time)
- M/M/1 Queue Average Time: W = 1 / (μ - λ)
- Probability of Waiting: Pw = λ / μ

**Financial Metrics**:
- Days Inventory Outstanding (DIO): 365 / Inventory Turns
- Days Sales Outstanding (DSO): Accounts Receivable / Daily Sales
- Days Payable Outstanding (DPO): Accounts Payable / Daily COGS
- Cash Conversion Cycle: DIO + DSO - DPO

**Network Optimization**:
- Transportation Problem: minimize ΣΣ c_ij × x_ij
- Facility Location: minimize Σ f_i×y_i + ΣΣ c_ij×x_ij
