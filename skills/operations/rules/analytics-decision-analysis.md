**Decision Trees**: Graphical representation of sequential decisions and outcomes.
- Decision Nodes (squares): Where decision-maker chooses
- Chance Nodes (circles): Where random events occur with probabilities
- Backward Induction: Solve working backward from terminal payoffs
- Node value = max(branches) for decision node; Σ p_i × outcome_i for chance node

**Expected Value**: Probability-weighted average of outcomes.
- EV = Σ (Probability × Outcome)
- Decision rule: Choose alternative with highest EV
- Particularly useful when same decision made many times
- Perfect Information Value: How much would we pay for certainty? (EV with perfect info - EV without)
- Expected Value of Sample Information (EVSI): Value of additional testing/research before deciding

**Sensitivity Analysis**: Which variables most affect optimal decision?
- Tornado diagrams: Visually show impact of varying each assumption
- Identifies which uncertainties matter most
- Threshold analysis: At what parameter value does optimal decision change?

**Bayesian Updating**: Update probability estimates as new information arrives.
- Prior probability: Initial estimate
- Likelihood: Probability of observing data given hypothesis
- Posterior: Updated estimate after observing data
- Application: Should we test further before deciding?
- Formula: P(A|B) = [P(B|A) × P(A)] / P(B)

**Multi-Criteria Decision Making**: When multiple objectives conflict.
- Weighted scoring: Assign weights to criteria, score alternatives
- Pareto analysis: Identify solutions dominating others on all criteria
- Trade-off analysis: Accept improvement in one criterion for worsening in another

**Real Options**: Value of flexibility when future is uncertain.
- Expand option: Ability to increase scale if favorable
- Abandon option: Ability to exit if unfavorable
- Wait option: Value of delaying to gather information
- Switch option: Ability to change from one process/product to another
