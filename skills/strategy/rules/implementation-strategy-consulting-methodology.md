**Definition**: Frameworks and approaches for developing and communicating strategy.

#### Hypothesis-Driven Approach

**Core principle**: Develop and test hypotheses rather than gathering data without direction

**Process**:
1. **Define problem**: What is the strategic question?
2. **Develop hypotheses**: What could be the answer?
3. **Identify data needed**: What would prove/disprove hypotheses?
4. **Gather data**: Research, analysis, interviews
5. **Test hypotheses**: Does data support or refute?
6. **Iterate**: Refine hypotheses; gather more data
7. **Synthesize findings**: Integrate into recommendation

**Advantages**:
- Focused research (not analysis paralysis)
- Efficient use of time and resources
- Clearer conclusions

#### MECE Principle

**MECE** = Mutually Exclusive, Collectively Exhaustive

**Mutually exclusive**: Categories don't overlap; item belongs in only one

**Collectively exhaustive**: All items fit into one category; no gaps

**Example - bad segmentation**:
- Enterprise, SMB, "Other"
- Problem: "Other" is too broad; not MECE

**Example - good segmentation**:
- By size: >$1B, $100M-$1B, $10M-$100M, <$10M
- Mutually exclusive: Each company in only one category
- Collectively exhaustive: All companies fit somewhere

**Using MECE**:
- Framework for organizing analysis
- Ensures complete coverage of issue
- Makes thinking clear and structured
- Identifies gaps in analysis

#### Issue Trees

**Issue tree**: Hierarchical breakdown of strategic question into component parts

**Structure**:
- Root: Main strategic question
- Branches: Key sub-questions rolling up to answer main question
- Leaves: Specific analyses or data points

**Using issue trees**:
- Ensures comprehensive analysis
- Identifies key levers
- Structures work plan
- Focuses team on critical analyses

#### Pyramid Principle for Communication

**Pyramid principle** (Barbara Minto): Organize recommendations hierarchically

**Structure**:
- **Apex (top)**: Main recommendation or conclusion
- **Level 1**: 3 supporting key points
- **Level 2**: Evidence and data supporting each point
- **Details**: Supporting facts

**Reading top-down**:
- Reader gets main message immediately
- Can read deeper to understand rationale
- Can scan or read thoroughly depending on interest

#### Best Practices for Strategic Recommendations

**Clarity**: Avoid jargon; use clear language

**Visuals**: Use charts and diagrams for clarity

**Data**: Support assertions with data and evidence

**Logic**: Recommendations follow logically from analysis

**Actionability**: Specific, implementable recommendations

**Conciseness**: Respect reader's time; no unnecessary length

**Executive focus**: Tailor depth to audience

**Engagement**: Tell a story; make it compelling
