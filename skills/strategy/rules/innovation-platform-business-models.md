**Definition**: Businesses creating value by connecting different user groups whose interactions create mutual benefit.

#### Pipeline vs. Platform

**Pipeline business**:

- Company makes product; sells to customer (one-direction value flow)
- Owns inventory; controls value creation
- Examples: Dell computers, Starbucks coffee, traditional manufacturing

**Platform business**:

- Company creates infrastructure for users to transact (multi-direction value flow)
- Owns no inventory; users create value through interaction
- Examples: eBay, Uber, Facebook, Amazon marketplace

#### Network Effects (Core Advantage)

**Definition**: Value of network increases as more users join

**Direct network effects**:

- User value increases with network size
- Example: Telephone (each new user makes network more valuable)
- Example: Social media (more friends = more value)

**Indirect network effects**:

- Value increases as complementary users join
- Example: Video games (more players → more games developed)
- Example: Operating systems (more users → more apps developed)

**Network effect strength**:

- Weak: Value increases slowly (productivity software)
- Strong: Value increases exponentially (social networks, payments)
- Critical mass: Minimum size before effects kick in

#### Two-Sided Platforms

**Definition**: Connect two distinct user groups where value depends on interaction

**The "chicken and egg" problem**: 

- Need both sides to create value
- Neither side joins without the other
- Solutions:
  - Subsidize one side initially (Uber subsidized drivers)
  - Build one side first, then attract other (Facebook → advertisers)
  - Find adjacent markets (Slack with developers → teams)

**Examples**:

- Uber: Drivers ↔ Riders
- eBay: Sellers ↔ Buyers
- LinkedIn: Job seekers ↔ Recruiters

#### Multi-Sided Platforms

**Three or more sides create complex value flows**

**Examples**:

- Video game consoles: Gamers ↔ Developers ↔ Manufacturers
- Advertising networks: Publishers ↔ Advertisers ↔ Users
- App stores: Developers ↔ Users ↔ Device manufacturers

#### Winner-Take-All Dynamics

**Why platforms show winner-take-most patterns**:

- Strong network effects create switching costs
- Larger platforms attract more users and complementors
- Data advantages improve matching and recommendations
- First mover to critical mass often wins

**Examples**:

- Search: Google (~90% market share)
- Social: Facebook/Meta dominance
- Ride-sharing: Uber dominance
- Payment networks: Visa/Mastercard duopoly

**Implications**:

- Speed to critical mass is crucial
- Incumbent dominance is hard to overcome
- New platforms must target underserved niches

#### Platform Revenue Models

**Freemium**: Free for users, premium for power users

- Example: LinkedIn free profiles, premium recruiting

**Commission**: Take percentage of transaction value

- Example: Uber (20-30%), eBay (10-15%)

**Advertising**: Monetize user attention

- Example: Facebook, Google, YouTube

**Subscription**: Monthly/annual fee for access

- Example: AWS, Apple App Store, Slack

**Hybrid**: Multiple revenue streams

- Example: Amazon (commission + Prime + advertising)
