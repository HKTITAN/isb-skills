---

- **Direct network effects**: Value increases as more people use (e.g., social networks)
- **Two-sided network effects**: Value increases as both sides (supply and demand) grow (e.g., credit cards)
- **Indirect network effects**: Value increases as complementary products become available (e.g., iPhone → App Store)
- **Economics**: Network effect markets favor concentrated winners (winnow-take-most); switching costs extremely high
- **Strategy implication**: Achieve critical mass quickly; subsidize one side if needed; focus on defensible position
